============================================================
                 AirCard · 快速入门指南
============================================================

1. 安装：
   将“AirCard”图标拖放到“应用程序”文件夹中。

2. 首次启动（macOS Gatekeeper）：
   由于 AirCard 是在本地构建的，macOS 可能会在首次启动时显示标准安全提示。

   方法一（推荐）：
   在“应用程序”文件夹中右键点击（或按住 Control 键点按）AirCard
   → 点击“打开” → 再次点击“打开”。

   方法二（通过终端）：
   sudo xattr -cr /Applications/AirCard.app

3. 无需额外配置：
   AirCard 可在 Apple 芯片和 Intel（x86）Mac 上完全独立运行。
   无需安装 Homebrew、Python 软件包或外部工具！

4. 使用方法：
   [Apple 钱包卡面]
   - 使用 USB 线缆连接 iPhone，并轻点“信任此电脑”提示中的“信任”。
   - 打开 AirCard（设备状态标记会变为绿色）。
   - 点击“扫描卡片”。
   - 在 iPhone 上连按两下侧边按钮，通过面容 ID 验证，然后轻点卡片。
   - 设置自定义卡面图片（点击卡片选择图片，或将图片拖放到卡片上）。
   - 点击“应用卡面”。
   - 在 iPhone 上关闭后台钱包App，即可查看新卡面。

   [锁屏密码主题（.passthm）]
   - 切换到“锁屏密码（.passthm）”标签页。
   - 拖放 .passthm 文件，或通过文件选择器选择文件。
   - 在交互式预览中查看键盘图片效果。
   - 点击“应用锁屏密码主题”。
   - 重新启动 iPhone。
   * 注意：支持所有系统语言（俄语、乌克兰语、英语等）及粗体文本！
